## Принципы, которые нужно соблюдать всегда

- GitHub — единственный источник истины. Никаких правок файлов напрямую в `/var/www`.
- Каждая живая папка в `/var/www`, подключённая к GitHub, должна соответствовать закреплённой папке-клону в `/root`, у которой есть `git remote -v` на реальный репозиторий (SSH-ключ на сервере уже привязан к аккаунту `ororegina111-spec` — можно коммитить и пушить прямо с сервера).
- Перед любой заменой файлов на продакшене — сравнение со старой версией, не слепая перезапись.
- `node_modules` в рабочих папках (`/root/*-temp`) можно свободно удалять для экономии места — npm пересоздаёт их заново командой `npm install`, это не риск потери данных.
- Пароль от root: если получаете ошибку `Permission denied` несколько раз подряд — сервер может временно заблокировать IP (Fail2ban); подождать или зайти через встроенную консоль в панели Beget (раздел «Облако»).
